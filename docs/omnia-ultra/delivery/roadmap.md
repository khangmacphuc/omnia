# Roadmap

## Phase 0: inventory and contracts

Source inventory, threat model, clean-room source ledger, schema registry,
status vocabulary, capability matrix, same-snapshot gates and risk register.

## Phase 1: durable kernel

Event journal, projections, session/epoch, provider freeze, attachment binding,
usage ledger, recovery and fault harness.

## Phase 2: interaction foundation

Composer, large paste, live Markdown/LaTeX input, voice contract, selection
reference, jump navigation, branch/copy/fork, queue/steer, request inspector,
accessibility and visual fixtures.

Run-control checkpoint/Continue/retry/compare behavior enters this phase only
after kernel state-revision, receipt and authority-continuity primitives exist.

## Phase 3: context and model control

Context compiler, memory/skills lifecycle, provider/model catalog, health,
effort profiles, model onboarding, usage/cost and retry controller.

## Phase 4: planning and Project Twin

Goals, roadmaps, blueprints, plans, task DAG, scheduler, graph/atlas, evidence,
staleness and smart overview.

## Phase 5: Ultra harness

Specialist agents, background sessions, fresh subagents, context forks, peer
teams, task leases, mailboxes, completion judge, critic, workflow compiler,
icons, motion and live inspector.

## Phase 6: file and studio

File bridge, artifact lineage, PDF/Office/LaTeX/web/canvas/image/audio/video,
render-and-verify, authorized segmented media assembly.

## Phase 7: engineering workbench

IDE context, LSP/AST, terminal, tests/coverage, Git/PR/Docker/CI/CD and worktrees.

## Phase 8: browser/machine runtime

Browser broker, privacy controls, authorized capture, virtual pointer,
isolated/persistent/headless/remote machines, typed privilege broker.

## Phase 9: research and omnichannel

Deep Research, learning/science/CP workbench, Google/Microsoft Workspace,
messaging, unified inbox and scheduler.

## Phase 10: adaptive intelligence and self-evolution

Feature/evaluation store, routing experiments, scheduled learning, drift,
rollback, supervisor, A/B update slots and durable self-restart.

## Phase 11: platform release

SDK, MCP, plugins, connectors, marketplace, Windows packaging, Android/web
clients, accessibility/security/performance certification.

Each phase may run parallel workstreams only when its dependencies and authority
contracts are already verified.
