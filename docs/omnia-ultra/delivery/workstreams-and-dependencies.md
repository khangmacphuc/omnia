# Workstreams

## Kernel/data

Owns event journal, schema, projections, recovery, storage and migration.

## Provider/observability

Owns frozen input, provider adapter, model catalog, health, usage, retry and cost.

## Interaction/UI

Owns composer, jump, branch/fork, queue, hover, inspector, accessibility, motion
and visual QA. UI cannot invent native state.

## Harness

Owns agents, workflows, context transfer, leases, mailboxes, Ultra and evaluation.

## Project Twin/artifacts

Owns graphs, atlas, docs, transforms, evidence and staleness.

## Runtime/security

Owns machine, browser, virtual pointer, capture, approvals, sandbox and secrets.

## Workbenches

Owns IDE/Git/Docker, documents/media, science/learning and integrations.

## Delivery

Owns gates, evidence, source ledger, coverage, changelog and release packaging.

## Dependency rules

- Kernel before durable UI claims.
- Frozen context/provider input before multimodal dispatch.
- Identity/lineage before agent UI.
- Capability broker before computer/browser side effects.
- Artifact lineage before model bridge claims.
- Usage ledger before cost dashboard claims.
- Source ledger before research claim.
- Supervisor/checkpoint before self-update.
- Visual fixture and render runner before visual pass claims.
- No workstream may silently fork an incompatible schema.
