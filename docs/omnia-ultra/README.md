# Omnia Ultra

This is the maintainable specification pack for the Omnia Universal Intelligent
Operating Workbench. Start with 00-START-HERE.md. Do not treat this folder as
proof of implementation; use the repository source, tests and
docs/IMPLEMENTATION_STATUS.md for current truth.

The pack is intentionally split into small files so a human or AI can read one
domain, fix one contract, scale one workstream and update evidence without
loading one enormous prompt.

For a single handoff prompt plus a smaller topic-by-topic goal map, start at
[`goal/README.md`](goal/README.md).
