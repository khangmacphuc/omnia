# Deep AI intelligence plane

AI subsystems may include:

- intent/task/difficulty classifier;
- model/provider/tool/machine router;
- context planner and retrieval planner;
- prompt optimizer;
- next-action recommender;
- retry/fallback advisor;
- error diagnosis;
- file/vision bridge selector;
- agent planner;
- scheduler optimizer;
- cost/quality optimizer;
- personalization engine;
- anomaly/drift monitor;
- evaluation engine;
- training scheduler;
- experiment manager.

Candidate methods:

- embeddings, sparse retrieval, reranking;
- KNN, classification, clustering and regression;
- XGBoost/gradient boosting;
- Bayesian optimization;
- contextual bandits;
- offline reinforcement learning;
- preference learning;
- active/self-supervised/weakly supervised learning;
- graph algorithms and graph embeddings;
- time-series forecasting;
- anomaly detection;
- constraint solvers and deterministic rules.

Deterministic safety and authority rules always precede learned routing.
Learned policies require baseline, dataset revision, metric, shadow mode,
rollback, drift monitoring, cost cap and privacy policy.
