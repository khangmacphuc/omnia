# Integrations and automation

Prioritize supported official APIs for Google Workspace, Microsoft 365, email,
Telegram, Discord, Slack, Teams, Zalo, Messenger, WhatsApp Business, Matrix,
Google Chat, GitHub/GitLab, cloud storage, Notion, RSS, webhooks and device
notifications.

Capabilities:

- unified inbox and thread mapping;
- search/summarize/draft;
- approval-before-send;
- scheduled send;
- attachments;
- calendar scheduling;
- task creation;
- notification routing;
- automation triggers;
- per-channel identity/persona/permission;
- token rotation and revocation;
- audit.

Scheduler triggers include time, cron, calendar, email, message, file, Git,
commit, push, PR, CI, webhook, provider health, budget, machine state and
artifact completion. Persist timezone, DST, missed runs, retry, dependencies,
locks, concurrency, budgets, approvals, notifications and history.

Never send an external message or public action without the effective policy.
