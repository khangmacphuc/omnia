# Engineering workbench

IDE features:

- multi-root workspace and trust;
- editor, search, outline, problems and terminal;
- LSP, AST, symbols, references, calls and data flow;
- debugger, tests, coverage, benchmark and profiler;
- IDE Context selector for current file, selection, open files, symbols,
  problems, terminal, test failure, Git diff, branch and PR;
- code retrieval with exact provenance and freshness.

Git tabs:

- Changes, Staged, Branches, Commits, History, Stashes, Worktrees, Conflicts,
  Remotes, Tags and Pull Requests.

Support hunk/line staging, worktree isolation, commit-message instructions,
pre-commit/pre-push hooks, secret scan, tests, PR descriptions, review threads,
CI status, merge policy and release notes. Existing user changes are never
silently committed.

Docker includes images, containers, volumes, networks, Compose, logs, terminal,
build, health, metrics, dev containers, scan and remote contexts. Cleanup uses
exact validated targets.
