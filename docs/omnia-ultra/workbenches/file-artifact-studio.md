# File and artifact studio

Ingest file, folder, archive, clipboard, URL, browser capture, cloud object,
camera, microphone and screen source. Detect by magic bytes, MIME, extension and
container structure.

If the selected model lacks a modality, create an explicit bridge derivative:

- DOCX to structured text, rendered pages and original package;
- PPTX to slide renders, text, notes and media manifest;
- XLSX to formulas, values, sheets and renders;
- PDF to text, page images, layout and metadata;
- image to OCR, regions and descriptions;
- audio to transcript, diarization and waveform;
- video to audio, transcript, keyframes, chapters and scene map;
- code to AST, symbol and dependency graph;
- data to schema, samples and statistics.

Keep original, derivative, tool/model, parameters, hashes and transformation
lineage. Let the user inspect exactly what the provider receives.

Integrated viewers/editors target PDF, Word, spreadsheets, presentations,
LaTeX, Markdown, web/canvas, diagrams, image, audio, video, notebook, datasets
and archives. Every visual artifact uses render-and-verify before a verified claim.
