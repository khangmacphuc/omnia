# Omnia Ultra master charter

Build Omnia as a native Windows 11, local-first, provider-neutral AI operating
workbench. It must unify chat, deep research, learning, coding, IDE, browser
use, computer use, file and media studio, Git/DevOps, automation, remote
machines, omnichannel integrations, memory, skills, agents, Project Twin and
adaptive intelligence.

The product must be:

- calm, premium, content-first and not a generic AI dashboard;
- useful with sensible defaults and extremely configurable for experts;
- durable across restart, crash, provider failure and self-update;
- observable down to request, attempt, tool, agent, artifact and UI action;
- provider-neutral with BYOK, local models and custom adapters;
- safe by capability, approval, sandbox and data-classification boundaries;
- extensible through typed tools, MCP, skills, plugins, workflows and SDKs;
- honest about unavailable, preview, planned and verified states.

## Product modes

Chat, Research, Learn, Build, Review, Operate, Automate, Discuss, Prompt
Workshop and Ultra are first-class modes. Mode changes workflow defaults, not
security authority.

## Runtime modes

None, Local Interactive, Local Background, Isolated, Persistent, Remote,
Hybrid and Auto are first-class environments. Auto chooses an environment
inside policy; it never grants privilege or silently relaxes isolation.

## Core loop

~~~text
intent
-> input normalization and large-paste handling
-> goal/context resolution
-> roadmap/blueprint/plan
-> queue/steer/schedule
-> model/provider/tool/agent/machine routing
-> durable execution
-> live inspector and telemetry
-> retry/fallback/repair when safe
-> output/artifact/evidence
-> verification and audit
-> memory/learning signals
-> Project Twin update
-> next-action suggestions
~~~

## Universal output rule

For every non-trivial project, Omnia generates Markdown plus structured JSON
graphs plus an offline interactive HTML/CSS/TypeScript/JavaScript atlas. Add
images, screenshots, diagrams, tests, source ledgers, evidence and release
readiness data when useful. Markdown is required but is not the only output
format.

## Minimum Ultra catalog target

At the Ultra milestone, provide at least 100 differentiated agent profiles,
150 meaningful skills/workflows, 250 typed tool operations, 40 persona packs
and 25 first-party integrations. Counts are floors, not a reason to create
filler. Every catalog entry needs a capability contract, permissions, tests,
failure modes and an evaluation suite.

## Quality interpretation

“Perfect” is operationalized as zero known P0/P1 defects, complete evidence for
the defined capability matrix, no silent data loss or authority expansion, and
continuous measurement-backed improvement. Never claim metaphysical perfection.
