# Background work inspector

The composer remains usable while work runs. A compact attention strip shows
active tasks, queued messages, approvals, errors and completed background work.

Clicking a task opens:

- goal and current phase;
- current input and output;
- instruction/context manifest;
- model/provider/effort;
- agent parent/children;
- tool and terminal events;
- browser/window/pointer target;
- file/artifact/diff;
- source/citation;
- queue/dependency;
- approval;
- retry/fallback;
- token/cost/latency;
- trace timeline;
- checkpoint and recovery.

Controls include steer, message agent, pause, resume, cancel, retry, fork,
change priority, change model/machine, open artifact, open terminal, promote
output, pin and archive.

Role icons and runtime-state glyphs are separate. State animation is subtle,
accessible, throttled offscreen and never the only status channel.
