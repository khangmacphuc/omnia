# Prompt intelligence

## Autocomplete

Use low-latency local or approved remote suggestions for phrase, constraint,
output format, file/symbol, agent, tool, model and missing-context completion.
Tab accepts, Escape dismisses, and sensitive fields are excluded.

## Enhance

Detect objective, audience, context, constraints, ambiguities, contradictions,
output format and acceptance criteria. Show a semantic diff and preserve user
intent. Never silently add authority or external side effects.

## Prompt Workshop

Allow multiple models/agents and the user to discuss a prompt. Track revisions,
critique, counterexamples, cost and context estimates. A user action such as
finalize/chốt inserts the selected prompt into the original composer without
manual copying and without automatically sending unless policy says so.

## Next action suggestions

Suggest add exercises, add problem types, deepen proof, broaden concepts,
applications, history, motivation, research gap, limitations, counterexamples,
experiments, sources, tests, coverage, benchmark, security audit, PR, release
notes, Project Twin update and next research question.

Auto-draft/queue/run modes require budgets, stop conditions, repeat detection
and visible expected cost.
