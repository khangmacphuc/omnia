# UI shell

Use a calm Windows 11 desktop shell with project/sidebar tree, main canvas,
right inspector, bottom terminal/run panel, tabs, split panes, detachable
panels, command palette, global search and per-project layouts.

Activities include Home, Chats, Projects, Goals, Roadmaps, Plans, Tasks,
Agents, Artifacts, Sources, Research, Learning, Memory, Skills, Tools, Models,
Providers, Browser, Machines, Studio, Changes, Branches, Commits, PRs,
Automations, Usage, Costs and Settings.

Support light/dark/system/high-contrast themes, density, typography, width,
radius, animation, icon packs, shortcuts and layout customization with reset
to recommended defaults.

First-click activation should not require a focus-only click for safe navigation,
hover, scroll or selection. Destructive actions still require explicit focus or
approval.

Accessibility:

- keyboard navigation and shortcuts;
- screen reader/Narrator;
- high contrast;
- reduced motion;
- visible focus;
- long Vietnamese labels;
- touch/pen hit targets;
- accessible graph alternatives;
- live-region throttling for streaming;
- transcript/captions for audio/video.
