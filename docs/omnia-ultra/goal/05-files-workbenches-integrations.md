# Files, artifacts and workbenches

Large pasted content and dropped files use a lineage-preserving bridge. Keep
original bytes, derived representations, checksums, extraction/OCR/chunking
metadata, citations, bridge-model identity, parameters, cost and debug trace.
When a model cannot read a format, use an approved transform or vision/text
bridge and show the exact derivative instead of pretending native support.

The in-app studio should preview and, where implemented, edit text/code,
Markdown/LaTeX, images, audio, video, PDF, DOCX, XLSX, PPTX, HTML/canvas and
archives. IDE context, LSP/AST, terminal, tests/coverage, Git/worktrees,
commit/push/PR, Docker and CI/CD use typed permissions, previewed hooks and
reversible operations. Research, learning, mail, calendar, Google/Microsoft
Workspace and messaging integrations use explicit connectors and scopes.

Local models are managed through an exact hash/license registry, resumable
download/import, runtime/resource planner, health and effort profiles,
evaluation lab, bridge/routing policy and safe dependency-aware removal. Local
throughput, load/prefill/decode time, RAM/VRAM and runtime revision remain
inspectable.

Authorized segmented media assembly may merge only user-accessible requests;
preserve provenance and never bypass DRM, paywalls, CAPTCHA, entitlements or
other access controls. All transforms and failures remain inspectable in the
artifact and request timelines.
