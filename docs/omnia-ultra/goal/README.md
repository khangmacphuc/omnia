# Omnia Ultra goal bundle

This folder is the split, copy-friendly view of the Omnia Ultra product goal.
It is intentionally small-file and AI-readable. The detailed normative
contracts remain in the sibling architecture, interaction, observability,
harness, project-twin, runtimes, security, workbenches and delivery bundles.

Read `00-copy-ready-prompt.md` when handing the goal to another AI. It is the
single canonical copy-ready execution contract, not proof that a capability
already ships. For current truth, always reconcile source, tests, evidence,
`04-CURRENT-STATE-BRIDGE.md` and `docs/IMPLEMENTATION_STATUS.md`. The delivery
bundle's `99-execution-prompt.md` is an alias only; do not maintain a second
product prompt there.

## Precedence

When a goal statement conflicts with a security boundary, accepted ADR, schema,
or current implementation evidence, follow the precedence rules in
`../02-PRECEDENCE-AND-STATUS.md`. Never turn a design requirement into an
implemented claim without a real native path, persistence/recovery, tests,
permission boundary and current evidence.
