# Ultra workflow

Ultra is highest model effort plus a verifiable workflow, not a larger spinner.

## Default phases

1. Normalize objective and latest correction.
2. Inspect repository/context and detect gaps.
3. Research with source ledger.
4. Generate goal, roadmap, blueprint, plan and task DAG.
5. Select specialist agents and execution primitive.
6. Fan out independent work where safe.
7. Review evidence and resolve conflicts.
8. Implement in small vertical slices.
9. Run deterministic tests.
10. Run security/accessibility/performance/visual audits.
11. Build artifacts and Project Twin.
12. Run an independent completion judge.
13. Synthesize result, limitations and next actions.
14. Checkpoint and continue if output is incomplete.

## Effort contract

Ultra can increase:

- reasoning budget;
- context quality;
- research depth;
- specialist count;
- verification passes;
- artifact richness;
- evaluation rigor.

It cannot silently increase:

- privileges;
- data destinations;
- retention;
- external side effects;
- budget;
- retry window;
- security risk.

## Stop conditions

Stop a loop when:

- goal acceptance criteria pass;
- budget is exhausted;
- max iterations reached;
- no material improvement;
- required authority is missing;
- deterministic failure is unrecoverable;
- user requests stop.

Report blocked criteria instead of claiming success.
