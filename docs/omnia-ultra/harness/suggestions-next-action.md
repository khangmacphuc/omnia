# Suggestions

Distinguish:

- prompt suggestion;
- action suggestion;
- workflow suggestion;
- research suggestion;
- learning suggestion;
- artifact suggestion;
- code-quality suggestion;
- risk suggestion;
- next-prompt suggestion.

## Learning suggestions

Add exercises, add problem types, deepen proof, explain intuition, show
non-examples, add applications, history, motivation, prerequisites, research
gaps, limitations, counterexamples, experiments, flashcards, spaced review,
mock exam and alternative solution methods.

## Coding suggestions

Add tests, increase coverage, fuzz, benchmark, refactor, document, audit
security/performance, create issue/commit/PR, update changelog and Project Twin.

## Research suggestions

Find primary sources, diversify evidence, identify contradiction, locate gap,
compare methods, replicate result, add limitations, update citations and
re-check freshness.

## Decision model

Rank suggestions by:

- relevance to goal;
- expected benefit;
- user history;
- evidence gap;
- cost;
- latency;
- risk;
- current budget;
- urgency.

Show why, expected outcome and estimated cost. Let the user accept, dismiss,
snooze, pin, disable or convert a suggestion into prompt/queue/steer/schedule.

Auto-run suggestions require explicit policy, stop conditions and budget.
