## Synthesis and limits

- `open-computer-use` exposes accessibility-tree and screenshot observations with platform-specific actions. Omnia should preserve layered DOM/UIA observation, explicit leases and permission boundaries; source is not Omnia native proof.
- `openharness` provides side-by-side agents/machines and keyboard-first attention routing. Omnia should model agent/machine/session identity and attention without copying its UI or remote runtime.
- `Async` makes Think → Plan → Execute → Observe, interruption and transparent tool activity first-class. Omnia should bind these states to receipts and native cancellation.
- `SuperSkill` combines project-jailed vault, derived FTS/knowledge graph and deterministic skill plans. Omnia should keep private memory project-scoped, derive indexes, and record provenance; do not import its implementation.
- `mcp-skillset` uses dynamic hybrid retrieval, on-demand skills and security validation. Omnia should load skills lazily, validate untrusted skill content, and record retrieval receipts; Python/MCP source does not prove Windows packaging.
