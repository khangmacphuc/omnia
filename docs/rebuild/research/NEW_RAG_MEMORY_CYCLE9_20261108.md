## Synthesis: cycle 9 decisions for Omnia

1. **Retrieval receipts become arm-aware.** Record lexical/vector arm candidate counts and errors, candidate IDs or hashes, reranker version, requested/returned `top_k`, threshold result and whether a source was unavailable. This extends the prior receipt-first decision with concrete degraded-provider evidence from `hypnagonia/rag`.
2. **Compaction fails safe.** A compaction attempt must either produce a bounded result with pre/post token estimates and strategy or return the original context with a machine-readable passthrough reason. Never report semantic preservation from lexical counts alone; preserve an explicit `semantic_verification` state.
3. **Provenance is content-stable.** Derive a hash from normalized source locator, content, source revision/version and status. Exclude request-local IDs and retrieval time from novelty identity so a reload does not appear to be new evidence. Keep unresolved graph/source links visible.
4. **Memory is bitemporal and scoped.** Durable claims/events need validity time and ingestion time, plus session/project/run scope. A historical query must state which time axis was used. Contradictory claims remain inspectable; they are not silently overwritten.
5. **Validation and privacy are receipts.** Reject malformed URLs, HTML/error pages, empty/oversized content and invalid top-k/filters before indexing. Record rejection counts/reasons, but omit query text and sensitive content from telemetry. Source content remains behind pointer permissions and consent.

## Omnia implementation/test targets

- Native RAG receipt schema: arm stats, candidate/source hashes, ranker/threshold, scope, source revision, truncation and unavailable/error state.
- Native compaction receipt: original/retained estimates, strategy, passthrough reason, model eligibility and semantic-verification status; negative tests for empty output, expansion, suspicious collapse and cancellation.
- Stable evidence fingerprint helper: normalize line endings, include locator/content/version/status, exclude request IDs/timestamps; test duplicate reload and changed revision.
- Bitemporal memory contract: `valid_from/valid_to`, `created_at`, session/project/run scope, contradiction status and schema version; test `as_of` versus `recorded_as_of` queries and stale/unfenced persistence.
- Search validation: reject `top_k <= 0`, malformed URL/HTML/error result, oversized content and unreadable pointer; preserve explicit rejected counts.

All targets remain **Partial/Planned** until implemented through the native boundary and verified with real runtime evidence. This document does not establish provider quality, Windows packaging, permissions, cancellation, or live browser/IDE integration.
