## Synthesis and distinct Omnia decisions

The strongest cross-source pattern is a continuity contract: sessions, workspace tabs, browser/editor panes and drafts keep stable IDs while the visible surface changes. Omnia will implement this as a native typed snapshot, with stale-revision rejection and receipts, rather than copying any reference store. A second pattern is bounded truthful state: compaction, file scans, browser captures and agent execution expose incomplete/unknown/error states and never turn a mock or stale snapshot into success. A third pattern is explicit attention: approvals, ask-user decisions, queued/steered messages and DoD progress are first-class events with keyboard-accessible controls.

The clean-room UI therefore gets these acceptance hooks:

* session/workspace/tab identity survives Chat to Browser to IDE switch and reload;
* every compaction/capture/retrieval/agent event has source, revision, status and a bounded evidence receipt;
* ask-user and approval controls expose semantic labels, focus order, and cancellation/timeout/error states;
* snapshots mark traversal/capture incomplete and block an overconfident Done;
* dynamic plugin/settings changes use validate, activate, rollback, with the previous state retained when activation fails;
* architecture review mechanically detects legacy renderer imports and external live editor embeds, then a human reviewer interprets findings.

No source is copied, imported or treated as a UI template. These decisions are inputs to src/rebuild/reference and the product DoD, pending independent review and implementation evidence.
