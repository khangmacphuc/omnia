## Synthesis: distinct Omnia decisions

1. **Feedback becomes durable evidence.** Repeated user/UI findings produce a versioned regression entry and the strongest mechanical/a11y/performance gate available; subjective visual review remains explicitly human-reviewed.
2. **Tool output is progressive.** Keep a compact status inspector visible, reveal streaming/approval only when active, and open full arguments/results in a portal. This reduces context pressure and avoids hiding permission decisions.
3. **Pointer/RAG is content-addressed.** Use source pointer identity plus content hash; unchanged content skips ingestion, changed/renamed files create a new receipt, deleted sources retain the latest safe snapshot.
4. **Workspace restore is atomic and recoverable.** Serialize Chat/Browser/IDE panes and tabs with active/MRU identity, validate before apply, pause intermediate events, and fall back to a safe default on corruption.
5. **Advanced settings are contextual.** Model/provider/effort, compaction, memory and retry controls belong to the current session and expose requested/applied/unsupported states. The top-level UI remains exactly Chat, Browser and IDE.
6. **Selection is a workflow primitive.** Selected output can reply, copy, export or open side chat; actions retain source message IDs and receipt lineage.
