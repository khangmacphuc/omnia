# Atomic implementation plan — rebuild-0001

## Phase 0 — governance and research

- Create canonical goal/spec/DoD/requirements and workflow gate.
- Audit all non-Zalo upstream extraction categories and installed ChatGPT package.
- Search new OSS every cycle; read exact source and produce synthesis workbench.
- Install/pin requested reference skills with provenance, especially Superpowers.

## Phase 1 — original foundation

- Add `src/rebuild` entry graph, independent tokens/layout/state and architecture guard.
- Build settings schema/hot reload and shared session/tab controller.
- Add reference workbench route outside the three product modes.

## Phase 2 — vertical slices

- Chat native bridge, non-project/project sessions, stream/queue/steer/ask-user,
  approvals, cancellation, model/effort and durable tabs.
- Pointer storage and RAG ingestion/retrieval receipts.
- Native browser lifecycle/capture and local IDE/editor/file tabs.
- Tools/MCP/plugins/skills/subagents, goals/plans/DoD and research citations.

## Phase 3 — hardening

- Observability, privacy, portability, permission boundaries, retry safety,
  accessibility and performance budgets.
- Positive/negative/cancel/race/reload tests; packaged desktop capture and UI QA.
- Independent audit, fix findings, update all canonical documents and README.

## Phase 4 — release loop

- Run rebuild gates and full appropriate tests/builds serially.
- Commit, tag and push only reviewed milestones with receipts and screenshots.
- Re-audit open criteria and continue until strict Done is complete.

Every task must state files, owner, input, output, dependency, verification command,
threshold and evidence path. Planned work is not a completion claim.
