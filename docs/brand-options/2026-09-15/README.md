# Omnia brand options — 15 September 2026

This folder is a visual shortlist for a more modern, coder-native Omnia identity.
It intentionally does not change the production logo or design tokens yet; choose a
direction first and then we can apply the selected mark and palette to the app.

## Open the gallery

Open `index.html` in a browser. Each `logo-*.svg` is also standalone and can be
opened directly from Explorer. `palette-board.svg` is a single-sheet overview of
the color systems.

## Shortlist

| Option | Direction | Why it fits a coder workspace |
| --- | --- | --- |
| 01 Terminal O | Aperture + prompt glyph | Reads as a tool immediately; friendly at 16 px and strong in a title bar. |
| 02 Grid O | Modular 3x3 mark | Feels like an editor/workspace system; easy to animate or reduce to a favicon. |
| 03 Cursor Gate | Brackets + caret | Directly references code, commands, and navigation without looking like an AI sparkle. |
| 04 Node Loop | Loop + connected nodes | Suggests projects, context, and workflows; more collaborative and less “assistant bubble”. |
| 05 Dual Chevron | Angular aperture | Crisp and technical; works well in monochrome and on dark graphite surfaces. |
| 06 Stack Mark | Layered bars | Signals composability and stacked context; especially good for project cards. |
| 07 Prompt Aperture | Prompt shell around an O | Most explicitly developer-facing; playful but still restrained. |
| 08 Hex Core | Hexagonal aperture | Stable, systems-oriented, and close to the current geometry while removing the purple bias. |
| 09 Bracket O | Brackets + circular core | Familiar to programmers and visually distinct from generic “AI” branding. |
| 10 Flowline | Continuous context path | Softer and more human; good if Omnia should feel like a calm workbench. |
| 11 Monogram OM | O + M construction | Strongest wordmark option when Omnia needs an ownable letterform. |
| 12 Scanline | O + terminal scanline | Retro-tool reference without becoming neon; works well for a compact app icon. |

## My recommendation

Start with **01 Terminal O** and palette **P01 Graphite / Signal Mint**. It is the
clearest “developer tool” signal, avoids the purple AI cliché, and keeps enough
warmth for a chat-first product. If you want a more enterprise/editor feel, pick
**02 Grid O + P02 Navy / Cobalt**. If you want the safest bridge from the current
icon geometry, pick **08 Hex Core + P08 Steel / Teal**.

## Palette guidance

- Keep the canvas and surfaces neutral (graphite, navy, or steel).
- Use one saturated signal color for active states and the logo.
- Reserve amber/red for state semantics, not for the entire brand.
- Avoid gradients in the core mark; use them only in optional marketing artwork.
- The mark should still work as one color at 16 px, 24 px, and 32 px.
