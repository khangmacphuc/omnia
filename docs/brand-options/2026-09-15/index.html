Omnia brand directions

12 coder-native marks and 9 neutral-first palettes. Open any SVG directly, or use this page as the quick comparison sheet. Production files are untouched until you choose a direction.

Logo shortlist

01 · Terminal O

Prompt glyph inside an aperture. Strongest default for a developer workbench.

02 · Grid O

Modular 3×3 construction. Editor-like and easy to simplify.

03 · Cursor Gate

Brackets and a caret. Direct code reference with a warm signal.

04 · Node Loop

Context, projects, and workflows represented as a connected loop.

05 · Dual Chevron

Technical and compact. Works particularly well in monochrome.

06 · Stack Mark

Layered context bars. Distinctive in project cards and side rails.

07 · Prompt Aperture

Most explicitly developer-facing while staying friendly.

08 · Hex Core

Closest evolution of the current geometry, with a calmer teal/cyan system.

09 · Bracket O

Familiar code brackets around a circular core; highly ownable at small sizes.

10 · Flowline

Human, calm, and continuous. Good for a context-first identity.

11 · Monogram OM

Letter-led option for a stronger wordmark and a more premium feel.

12 · Scanline

Subtle terminal reference with an ice-blue signal and no neon glow.
